# Primeiros passos: variáveis e texto

Escreva a função `saudacao`, que recebe um nome e devolve uma frase de boas-vindas.

## Exemplos

```python
saudacao("Tiago")  →  "Olá, Tiago!"
saudacao("Ana")  →  "Olá, Ana!"
```

## Dica

Texto em Python fica entre aspas. Para juntar um texto com outro, você pode usar
`+`, ou uma f-string: `f"Olá, {nome}!"`.

## Como fazer

Abra `resolva.py`, escreva a função e rode, aqui nesta pasta:

