# Listas e laços: percorrer e somar

Escreva a função `media`, que recebe uma lista de notas e devolve a média delas.

Se a lista estiver **vazia**, devolva `0` — e não um erro. Esse é o caso que quase
todo mundo esquece.

## Exemplos

```python
media([10, 8, 6])  →  8.0
media([7])  →  7.0
media([])  →  0
```

## Dica

Existe um jeito manual (um laço `for` somando) e um jeito curto (`sum` e `len`).
Faça primeiro o manual: é ele que ensina o laço. Depois tente o curto.
